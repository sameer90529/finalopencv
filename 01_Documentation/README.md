# VisionDNA: AI-Based Visual Digital Twin Documentation

Welcome to the comprehensive documentation directory for VisionDNA.

### Directory Structure:
- **`Project_Overview/OVERVIEW.md`**: Mission, capabilities, hardware & software stacks, and system requirements.
- **`System_Architecture/ARCHITECTURE.md`**: Complete end-to-end pipeline diagrams and dataflow specifications.
- **`Technical_Documentation/MODULE_GUIDE.md`**: In-depth mathematical formulas, kinematic algorithms, and heuristics.
- **`Technical_Documentation/API_REFERENCE.md`**: Public API classes, methods, and parameters.

---

### Running Applications:
- **Streamlit Command Center**: `streamlit run 12_Main_Application/dashboard.py`
- **Desktop Application**: `python 12_Main_Application/app.py`
- **End-to-End Test**: `python 09_Testing/Integration_Tests/test_end_to_end_pipeline.py`
