# VisionDNA AI & Deep Learning Model Repository

This directory houses the neural network model weights and configurations powering VisionDNA's real-time perception pipeline:

- **Pose_Models/**: yolov8n-pose.pt - Single-pass person detection and 17 COCO keypoint estimation.
- **YOLO_Models/**: yolov8n.pt - Lightweight standard person bounding box detector.
- **Emotion_Models/**: emotion_ferplus.onnx and emotion_model.hdf5 - Facial expression classifiers.
- **Model_Configurations/**: Model manifests, input layer definitions, and hardware runtime parameters.
